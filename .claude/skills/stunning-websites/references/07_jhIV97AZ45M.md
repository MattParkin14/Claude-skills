# 7 (actually 8-9) Techniques That Make Claude Code Websites Look $10,000
Jono Catliff · 24 Mar 2026 · 50k views · https://www.youtube.com/watch?v=jhIV97AZ45M
(FULL transcript, user-supplied)

Framing: "Every one of these was built with AI and every one looks like AI slop - same boring layout, gradients, same stock components. This one was also built with AI but nobody would have guessed. The difference isn't the tool, it's eight techniques nobody bothers to use."

1. **claude.md with a role line.** "Every single project in Claude should have a claude.md file... the only thing that actually matters here really is this paragraph: **behave like a senior UI designer and front-end developer.** And surprise, it's going to act like a senior developer."
2. **Clone a site you love, properly.** Ask Claude to *find* beautiful sites for you (that's how he found Railway). Then: **give Claude the live URL AND a screenshot.** The prompt tells it to go to the URL, analyse the site, detect the HTML/CSS, and clone it - the screenshot lets it "visually see exactly what we are seeing ourselves." Baseline generic build vs cloned build is night and day, "first shot, absolutely beautiful." Dribbble is the secondary source; for video mockups, pause and screenshot the frame.
3. **Name the stack: Tailwind CSS + shadcn/ui.** Tailwind = low-level styling (padding, widths, columns). shadcn = a reusable component library you import - accordions, avatars for testimonials, buttons - so components stay consistent across pages instead of being reinvented per section.
4. **Backgrounds are a deliberate, separate step.** Used "a radial gradient with blurred purple, blue, pink and teal circles positioned around the page." Reason: on a minimalist site with little content, a background "adds texture and character... makes it feel a bit more complete or full."
5. **Animation via GSAP + Framer Motion, with named timings.** GSAP for scroll-triggered entrances (text and images gliding in, bars animating). Framer Motion / motion.dev for hover states. **Specific number: hover enlarge over 300 ms** - "otherwise it would be kind of jagged and rough. It's really smooth." Also flags a real failure: the motion clipped a subtitle - check for clipping after adding animation.
6. **3D via Spline + Three.js.** Three.js for generative background graphics; **Spline for hand-picked pieces**: log in free, Community tab, pick a scene, **Remix it into your own project, delete the demo text and stray logos FIRST** (otherwise you get text layered on text), then Export -> code export -> paste the link into Claude with "use this Spline graphic above the fold for the background." Gotcha he hit: a hard edge where the graphic ends - fix with a gradient from the graphic's colour to transparent so it fades into the page. Comparison point: the Stripe.com hero feel.
7. **Typography from Google Fonts.** All free. Either name the font or ask Claude to pick. **Sort by category** (calligraphy/handwriting/informal/formal/upright) to browse by feel. One font for headers, one for body. "It's viewed as something tacked on at the end... honestly it changes the whole entire look and feel of a website."
8. **Edit with screenshots.** "Instead of trying to describe how you want to change a graphic over here or over there, take a screenshot and describe what you want changed in that screenshot." Used it to turn a lonely single graphic into a 4x4 grid. Called "one of the most effective ways."
