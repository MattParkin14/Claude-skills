# copywriting

A copywriting coach and playbook. It runs an **interview first**, builds a **creative brief**, then **drafts and refines** using principles distilled from 16 expert videos. The single most repeated lesson across every source: **90% of copywriting happens before you write a word.** So this skill refuses to draft blind — it pulls the best ideas and details out of the writer first.

## When this fires
Any request to write, plan, review, improve, or critique marketing copy (emails & sequences, sales/landing pages, VSLs, ads, headlines, subject lines, hooks, CTAs, product descriptions, social captions, web copy).

## The reference files (read before drafting)
- `references/playbook.md` — the distilled principles, the persuasion foundations, and the proven structures/templates for each asset (AIDA, PAS, the 7-step sales letter, VSL, sales page, email structures, headline formulas, awareness × sophistication). **Read this before you draft anything.**
- `references/brief-and-refine.md` — the discovery questions, the Creative Brief template, the refine checklist, and the AI-slop word blacklist.

## Workflow

Follow these phases in order. Do not skip the conversation — it is the point of this skill.

### Phase 1 — Frame the job (fast, mostly multiple-choice)
Use the **AskUserQuestion** tool to lock the fixed variables in one or two rounds (these have obvious discrete answers, so don't make the user type them):

1. **Asset** — email / email sequence / sales page / landing page / VSL script / ad / headline set / subject lines / product description / social caption / other.
2. **Channel/placement** — where it runs (e.g. cold email, newsletter, Meta/Google ad, website hero, Instagram, LinkedIn). Copy that works on one channel won't land on another.
3. **Audience temperature** — cold (never heard of them) / warm (on the list, knows them) / hot (ready to buy). This decides structure: cold → grab attention first (AIDA/VSL); warm → PAS; hot → offer + urgency.
4. **The one action** — the single thing the reader should do (reply, click, book a call, buy, opt-in). One asset, one job.
5. **Tone** — e.g. punchy/direct, warm/friendly, authoritative/expert, playful, plain/no-hype.

If the user already stated any of these, don't re-ask — confirm and move on.

### Phase 2 — Dig for the gold (open questions, the creative core)
This is where great copy is actually made. Ask the **open** discovery questions from `references/brief-and-refine.md`, but conversationally and **a few at a time (ideally one focus per message)** — do not dump a 12-question form. Adapt to the answers, follow the interesting threads, and push for specifics: names, numbers, real quotes, concrete detail. Vague inputs produce vague copy.

Cover, at minimum:
- **The offer** — what it actually is and what it truly does for the buyer (outcome, not features).
- **The ONE big idea / angle** — the single compelling message this piece will hang on (Rule of One). Help the user find it; the hard part is picking one.
- **The reader's pain & desire in their own words** — how would *they* describe the problem? What do they secretly want?
- **Proof** — testimonials, numbers, case studies, credentials, guarantees, anything falsifiable.
- **The unique mechanism** — what can you say that a competitor literally could not? ("Never write an ad a competitor could sign.")
- **Objections** — the top reasons they'd say no.
- **Voice** — how the brand/person actually talks (ask for a sample of their writing, or offer to build a short voice profile).

If the user doesn't know their audience's exact language, **offer voice-of-customer research**: mining Reddit, Amazon reviews, or forum/Facebook-group comments for the phrases real buyers use (you can run this with web search if useful).

### Phase 3 — Write the brief, get a thumbs-up
Assemble answers into the **Creative Brief** (template in `references/brief-and-refine.md`): audience + temperature, the one big idea, primary emotion (toward-pleasure or away-from-pain), promise, proof, unique mechanism, objections, the one CTA, voice notes, and chosen structure. Show it and ask the user to confirm or adjust **before** drafting. This brief is a deliverable in its own right.

### Phase 4 — Draft
Only now, write the copy. Read `references/playbook.md` first and:
- Pick the structure that matches the asset + audience temperature (map in the playbook).
- Open with a hook that earns the second line; make the reader "get it" in ~2 seconds.
- Lead with benefits/outcomes; turn every feature into "[feature] so you can [benefit]."
- Keep to one big idea; every line reinforces it. Cut anything that doesn't.
- Be concrete and falsifiable — point to specifics and facts, not adjectives.
- Write short: line-by-line, short paragraphs, everyday words, one clear CTA.
- Match the voice profile. Where useful, offer **2–3 variations** of the headline and CTA rather than one.

### Phase 5 — Refine (don't ship the first draft)
Great copy is rewriting. Run the **refine checklist** in `references/brief-and-refine.md`:
- Score every line against the 3-rule test (visualize? / falsify? / can nobody else say it?) and the 4 foundations (specific / emotional / memorable / positioned).
- **Read it aloud** (or read it back) to catch clunk and boredom.
- Cut dead words (Kaplan's Law: any word not working for you is working against you).
- Strip AI-slop tells (blacklist in the reference file); make sure it sounds human and like *them*.
Then present the refined copy, and briefly note what you'd A/B test.

## Judgment calls (where the 16 experts disagree — decide with the user)
- **Structure vs. freedom:** Most sources lean on templates (AIDA/PAS/VSL); Harry Dry and elevated-DR practitioners warn rigid frameworks make copy generic. Use structure as a scaffold to hit the beats, then rewrite for voice and specificity — never ship formula-shaped copy.
- **Hand-copying great ads:** Halbert/Copy That swear by it; Cattoni says it's useless unless you already grasp the underlying principles. Recommend it only alongside *analysis* of why the copy works.
- **How much AI to use:** Some generate near-complete drafts; most insist AI only accelerates the 80% before writing and produces a rough draft you must rewrite. Default: use AI/this skill to research, structure and draft, then the human edits, adds story, and de-slops. Never ship raw AI copy.
- **Length:** Match to asset + temperature. Emails ~200–400 words that "sell the click" (the next page sells); VSLs/sales pages run long with full argument; hot-audience promos can be very short.
